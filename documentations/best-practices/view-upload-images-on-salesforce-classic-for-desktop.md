# View / Upload images on Salesforce Classic for Desktop

SharinPix can be integrated into Salesforce Classic in different ways.

For instance, it is possible to integrate SharinPix into your own Visualforce development or add the same on your page layouts.

![](<../.gitbook/assets/a9dd39fa-7e37-4b41-b2f0-630c69acacd5 (1).jpg>)

Here are the possibilities you have :

* [Using SharinPix "Album" Canvas App](https://github.com/SharinPix/documentation/blob/main/documentations/getting-started-with-sharinpix/basic-setup-step-3a-for-classic-users-setup-sharinpix-for-salesforce-classic.md)
* [Using Visualforce page Without A Controller (Admin Friendly)](../features/main-integration/using-on-classic-with-a-visualforce-page-without-an-apex-controller-admin-friendly-version.md)
* [Using VIsualforce page With a Controller (Developer skills required)](../features/main-integration/using-on-classic-with-a-visualforce-page-with-an-apex-controller-developer-skills-required.md)

The above links point to detailed instructions on how to configure each experience.

**Best Practice is to use the Visualforce page integration.**

If you want more flexibility, you should use the version with a Controller but, this requires some developer skills.
