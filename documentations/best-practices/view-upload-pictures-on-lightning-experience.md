# View / Upload Pictures on Lightning Experience

SharinPix uses Lightning components to integrate with Salesforce Lightning Experience.

![](<.gitbook/assets/Screenshot_2020-11-28_at_18.11.37 (1).png>)

{% hint style="warning" %}
To access the SharinPix Lightning components, **My Domain** should be configured for your organization.

Check [here](https://app.gitbook.com/s/2putv2B9RAZpym8daOH2/basic-setup/basic-setup-step-3b-for-lightning-users-setup-sharinpix-for-lightning-experience#id-1.-get-my-domain) for more details on how to make this configuration.
{% endhint %}

These Lightning components can be added:

* to a [record Page](https://app.gitbook.com/s/5EvYRrLbUyvRh8o1jmMG/features/main-integration/using-on-a-lightning-record-page) or a [home Page](https://app.gitbook.com/s/5EvYRrLbUyvRh8o1jmMG/features/main-integration/using-on-the-lightning-home-page)
* as a [Lightning Action](https://app.gitbook.com/s/5EvYRrLbUyvRh8o1jmMG/features/main-integration/using-on-lightning-with-sharinpix-album-lightning-action) (so that you can use a button to open a SharinPix Album)
* in [Flows](images-features-in-your-salesforce-flow.md)

**The Best Practice is to check all the SharinPix Lightning components, which are all listed here:**

[Overview of the SharinPix Lightning Components](https://app.gitbook.com/s/5EvYRrLbUyvRh8o1jmMG/lightning-web-component/overview-of-the-sharinpix-lightning-components)
