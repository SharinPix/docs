# View / Upload Pictures on Salesforce mobile App

SharinPix integrates with all the Salesforce mobile Experience.

If you are using Salesforce Lightning Experience, you will get the same experience as configured on the desktop using the Phone form factor within the Page Builder.

If you are using Salesforce Classic Experience, you will have to setup actions (buttons) to access the SharinPix Album in a separate window.

![](<../.gitbook/assets/Screenshot_2020-11-28_at_18.36.15 (1).png>)

Here are all the possibilities you have to integrate in Salesforce mobile:

* with a [Phone form factor on the Record Page](https://github.com/SharinPix/documentation/blob/main/documentations/getting-started-with-sharinpix/basic-setup-step-3c-for-new-salesforce-mobile-app-users-setup-sharinpix-for-mobile-lightning-experience.md) for the "Lightning Experience"
* with the [Mobile Launcher Lightning Component](../features/main-integration/using-on-lightning-with-sharinpix-mobile-launcher-lightning-component-admin-friendly.md) to use SharinPix Mobile App
* with a [Lightning Action for Salesforce mobile app](https://github.com/SharinPix/documentation/blob/main/documentations/getting-started-with-sharinpix/basic-setup-step-3d-for-old-salesforce-mobile-app-users-setup-sharinpix-for-mobile-classic-implementation.md) for the "Classic experience"

**Best Practice is to use the**[**SharinPix Mobile App**](../mobile-app/sharinpix-mobile-app-how-it-works.md) **for any optimisation regarding people taking multiple pictures on the field and having connectivity concerns (as this can work even offline).**
