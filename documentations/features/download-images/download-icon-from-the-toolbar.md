# Download icon from the toolbar

The ensuing steps outline the way to download a specific single image from the **SharinPix Album** from the toolbar.

{% hint style="warning" %}
**Note:**&#x20;

The present example requires that the ability **image\_download** is already enabled on the current SharinPix Album. Refer to the following article to know more about SharinPix Abilities: [SharinPix abilities](../../access-and-security/sharinpix-abilities.md).
{% endhint %}

{% hint style="success" %}
**Tips:**&#x20;

It is recommended to download the current image using the method outlined below rather than right-clicking on it and selecting **Save image as...**
{% endhint %}

* Access the **Full View** of an image by clicking on its thumbnail.

<figure><img src="../../.gitbook/assets/image (11) (1).png" alt=""><figcaption></figcaption></figure>



* Click on the **download** icon, as shown below, to download the current image.

<figure><img src="../../.gitbook/assets/image (12) (1).png" alt=""><figcaption></figcaption></figure>

* Upon clicking on the **download** icon, the current image is downloaded with its original **format** and **resolution**.
