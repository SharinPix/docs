# Download Images as PDF

Download selected items from a SharinPix Album as one PDF file.

{% hint style="warning" %}
**Prerequisite**

Enable **Download Original As PDF** in the album's SharinPix Permission record. See [Create and use a SharinPix Permission record](../../access-and-security/sharinpix-permission-object-how-to-create-and-assign-custom-permission.md) for more information on how to create a SharinPix Permission record and assign it to an album component.
{% endhint %}

### Configure the permission

In the **Menu** section, select **Download Original As PDF**.

<figure><img src="../../.gitbook/assets/DOC SF - 1920 x 1080 (2) (3).png" alt="Download Original As PDF option in a SharinPix Permission record"><figcaption></figcaption></figure>

For ZIP downloads, see [Download multiple images as a ZIP](sharinpix-album-multiple-image-zip-download.md).

### Download a PDF

1. Select images in the album.

<figure><img src="../../.gitbook/assets/DOC SF - 1920 x 1080 (3) (4).png" alt="Selected images in a SharinPix Album"><figcaption></figcaption></figure>

1. Open the **Selection** menu.

<figure><img src="../../.gitbook/assets/DOC SF - 1920 x 1080 (4) (3).png" alt="Selection menu in a SharinPix Album"><figcaption></figcaption></figure>

1. Select **Download**.

<figure><img src="../../.gitbook/assets/DOC SF - 1920 x 1080 (6) (4).png" alt="Download option in the selection menu"><figcaption></figcaption></figure>

1. Select **Download Original As PDF**.

<figure><img src="../../.gitbook/assets/DOC SF - 1920 x 1080 (7) (3).png" alt="Download Original As PDF option"><figcaption></figcaption></figure>

{% hint style="info" %}
Select individual pages from different PDF files in any order. SharinPix combines them into one PDF in that selection order.
{% endhint %}
