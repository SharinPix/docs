# Single Image download

The sections below enumerate the different methods to download a single image from the [**SharinPix Album**](../../lightning-web-component/sharinpix-album-lwc.md)**.**

* [Download icon from the toolbar](single-image-download.md#download-icon-from-the-toolbar)
* [Browser Download: right-click menu](single-image-download.md#browser-download-right-click-menu)

## Download icon from the toolbar

It is possible to download a specific image with its original format and resolution by clicking on the **download** icon from the toolbar. Access the following article to know more: [Download icon from the toolbar](download-icon-from-the-toolbar.md)

![](../../.gitbook/assets/download_icon.png)

## Browser Download: right-click menu

It is possible to download a specific image using the built-in options in a web browser. Access the following article to know more: [Browser Download – right click menu](browser-download-right-click-menu.md)
