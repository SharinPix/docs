# How to copy an image from SharinPix

The right click on an image in SharinPix doesn't work when annotation are enabled.

But if you use the Show/Hide annotation tool, you can hide the annotation and get the copy working back.

{% hint style="warning" %}
The copied image is a lower resolution version than the one uploaded. To get the best one copied, you should use the setting tool to change resolution back to original prior to copy.
{% endhint %}
