# The Tag Filters

* To filter the results by certain tags, select **Any** **of** or All of. **Any** **of** searches for all the images with at least one of the selected tags. **All** **of** searches only for images that have all the selected tags.
  * For example, if you want all the images with the tags **Land** and **Sea** , select both tags from the list.
  * Once the **Report** **ID** is selected, the "search" will automatically start.
