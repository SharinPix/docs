# Using the Add button on a desktop

Uploading an image on a SharinPix Album from a desktop workstation is as easy as clicking on a button.

* To upload an image on a desktop device onto a SharinPix Album, click on the **+ Add** button as shown in the screenshot below.

![](../../.gitbook/assets/dropzone.png)

The same button is also available once images are already present on the album and has the same behavior.
