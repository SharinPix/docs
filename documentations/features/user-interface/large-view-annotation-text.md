# Large View: Annotation – Text

## Large View

* Access the large view of an image by clicking on its thumbnail.

![](../../.gitbook/assets/AnnotationText0.png)

## Editing mode

* Access the **editing** mode by clicking on the **edit** icon.&#x20;

<figure><img src="../../.gitbook/assets/image_1.png" alt=""><figcaption></figcaption></figure>

## Add text

* Add text to an image by selecting the **text icon.**

<figure><img src="../../.gitbook/assets/image_2.png" alt=""><figcaption></figcaption></figure>

* Enter the desired content inside text box.

![](../../.gitbook/assets/AnnotationTextSS4.png)

![](../../.gitbook/assets/AnnotationTextSS5.png)

* The text is now displayed on the image.

![](../../.gitbook/assets/AnnotationTextSS6.png)

* The text can be:
  * **moved**
  * **rotated**
  * **resized**

by using the handle.

![](../../.gitbook/assets/AnnotationTextSS7.png)

![](../../.gitbook/assets/AnnotationTextSS8.png)

![](../../.gitbook/assets/AnnotationTextSS9.png)

## Change text

* The text content can be modified by double-clicking on it.

![](../../.gitbook/assets/AnnotationTextSS10.png)

![](../../.gitbook/assets/AnnotationTextSS11.png)

![](../../.gitbook/assets/AnnotationTextSS12.png)

## Change text color

* Select the desired color from the color-palette by clicking on it as shown below.

![](../../.gitbook/assets/Annotationtext15.png)

* The text is now colored as previously selected.

![](../../.gitbook/assets/AnnotationTextSS13.png)

## Delete text

* A text can be deleted from the image by clicking on the eraser icon and then click the text you want to delete.

![](<../../.gitbook/assets/AnnotationDelete3 (1).png>)

* Text is now removed.

![](../../.gitbook/assets/AnnotationTextDelete2.png)
