# Thumbnail View - Album Gallery Navigation

## Overview

This article demonstrates how to configure the gallery navigation inside the SharinPix Album component. There are two main navigation modes:

* [Default - Thumbnail view with pagination at the bottom](thumbnail-view-album-gallery-navigation.md#gallery-navigation-page)
* [Scroll - Thumbnail view with a scroll bar](thumbnail-view-album-gallery-navigation.md#gallery-navigation-scroll)

### Gallery Navigation Page

The page navigation provides a paginated way to navigate through the SharinPix Album UI. It is enabled by default under the label **Gallery navigation** in the [SharinPix Permission](../../access-and-security/sharinpix-permission-object-how-to-create-and-assign-custom-permission.md) assigned to the album.

### Gallery Navigation Scroll

The scroll navigation provides a scrollable way to navigate through the SharinPix Album UI. It can be enabled by configuring the **Gallery navigation** to **Scroll** in the [SharinPix Permission](../../access-and-security/sharinpix-permission-object-how-to-create-and-assign-custom-permission.md) assigned to the album.
