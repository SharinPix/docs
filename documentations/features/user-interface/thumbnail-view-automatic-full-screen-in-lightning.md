# Thumbnail View – Automatic Full Screen in Lightning

### Thumbnail view – Automatic Full Screen in Lightning

On Lightning, when clicking on a picture, the Full Screen view could be applied automatically.

![](<../../.gitbook/assets/image (38).png>)

![](<../../.gitbook/assets/image (39).png>)

This behavior could be modified from the **SharinPix Album** component parameters by deselecting the checkbox **Use Full screen Image Viewer.**

{% hint style="info" %}
**Information:**

The **SharinPix Album** component was previously named **SharinPix**.
{% endhint %}
