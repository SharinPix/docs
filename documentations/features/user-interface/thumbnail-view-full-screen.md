# Thumbnail View – Full Screen

To access the Full Screen mode you can use the button from SharinPix album header.

![](<../../.gitbook/assets/Copy of Click on the.png>)

{% hint style="info" %}
**Info:**

The Full Screen mode opens SharinPix in a new tab on your browser.
{% endhint %}

{% hint style="danger" %}
**Alert:**

When you open SharinPix in full screen, it stays connected to your Salesforce window. If you close or refresh your Salesforce window, you'll see a message letting you know that some features, such as Image Sync, will not work properly. To fix this, simply reopen SharinPix in full screen mode from Salesforce.

**To avoid disruptions, we recommend keeping the Salesforce window open while using SharinPix in full screen. Closing or refreshing the parent window can interrupt the connection and impact functionality.**
{% endhint %}
