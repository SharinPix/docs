# Thumbnail View - Group PDF

Group PDF is a setting in [SharinPix Abilities](../../access-and-security/sharinpix-abilities.md) and [SharinPix Permission](../../access-and-security/sharinpix-permission-object-how-to-create-and-assign-custom-permission.md) which permits to group pages uploaded from the same PDF file into a single entity.

On the preview pane, the thumbnail will then show a PDF icon to mark the image as a cover of this group of page.

![](<../../.gitbook/assets/image (51).png>)

When you click on this thumbnail, you access to the group of pages as images and can get back to the previous thumbnail list using the "Back" button

![](<../../.gitbook/assets/image (52).png>)

{% hint style="warning" %}
**Note:**

If the PDF icon is not visible on the thumbnail, this means that **max pages** on your org has not been set to more than 1.

This functionality can be edited by root only. ([Should contact support team](../../getting-started-with-sharinpix/how-to-contact-support.md))
{% endhint %}
