# Thumbnail View – Image Selection

Using the Check box on the top left corner of the thumbnail you can select image(s).

* Selecting 1 image.

![](<../../.gitbook/assets/image (53).png>)

* Selecting multiple images.

![](<../../.gitbook/assets/image (54).png>)

Then the SharinPix menu appears on the SharinPix album header and gives you access to extended command to work on the current selection.

![](<../../.gitbook/assets/image (55) (1).png>)

Note that you can cancel the selection at any moment by using the escape Key or the Cancel command from the menu.
