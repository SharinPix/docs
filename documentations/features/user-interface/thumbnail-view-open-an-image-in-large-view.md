# Thumbnail View – Open an Image in Large View

To access the large view, you just have to click on any image in the Thumbnail view.

The large view is composed of 3 main parts:

* [Top Toolbar](thumbnail-view-open-an-image-in-large-view.md#top-toolbar)
* [Preview Pane](thumbnail-view-open-an-image-in-large-view.md#preview-pane)
* [Navigation](thumbnail-view-open-an-image-in-large-view.md#navigation)

## Navigation

{% hint style="success" %}
Note: You can navigate through images using the arrow on each side of the picture as well as the keyboard arrows or by sliding with your thumb if you are on a touch device.

Using the escape key at any time you will get back to the Thumbnail view.
{% endhint %}
