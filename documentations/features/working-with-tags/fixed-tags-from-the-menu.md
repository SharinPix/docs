# Fixed Tags from the menu

{% hint style="info" %}
The **fixed tags** can be created, edited or deleted right from the administration dashboard.
{% endhint %}

![](<../../.gitbook/assets/image (12) (6).png>)

* Select one or more images.
* Fixed tags can be accessed from the **Command Menu** as shown below.

![](<../../.gitbook/assets/image (13) (7).png>)

* Select one of those **fixed tags** to assigned it to the previously-selected image(s).

![](<../../.gitbook/assets/image (14) (6).png>)
