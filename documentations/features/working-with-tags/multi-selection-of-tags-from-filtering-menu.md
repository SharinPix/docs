# Multi-Selection of Tags from Filtering Menu

Once Tags has been added to an album, the Filtering Menu permits to choose which Tag to filter with.

This Filtering Menu contains the list of tags present on images with checkboxes and labels.

* Clicking on the checkboxes, enables filtering using multiple tags (and keep the menu open)
* Clicking on labels, selects only one tag and unchecks any previously selected checkboxes (and close the menu immediately)

{% hint style="info" %}
Filtering Modes could be changed from [Global Settings](https://app.gitbook.com/s/2putv2B9RAZpym8daOH2/advanced-configuration-customizing-your-sharinpix-components-with-sharinpix-permissions) or [SharinPix Permission](../../access-and-security/sharinpix-permission-object-how-to-create-and-assign-custom-permission.md)

Filter multiple tags using one of the following logics:

* ‘All of’ (AND)
* ‘Any of’ (OR)

Default mode: ‘All of’ (AND)
{% endhint %}
