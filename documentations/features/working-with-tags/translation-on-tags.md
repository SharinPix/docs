# Translation on Tags

This article explains how tag labels are used to manage translations for tags.

Follow the ensuing steps to add a translation on a tag:

* Access the admin dashboard and click on the "Tag" tab.

<figure><img src="../../.gitbook/assets/DOC - Active Admin Tag (2).png" alt=""><figcaption></figcaption></figure>

* Click on "Create a Tag"

<figure><img src="../../.gitbook/assets/DOC - Active Admin Tag (1) (1).png" alt=""><figcaption></figcaption></figure>

* Enter the details of the Tag and click on "Create Tag"

{% hint style="warning" %}
**Note:**&#x20;

Currently, only English, French, and German are supported as translation options for tags.
{% endhint %}
