# Basic Setup Steps - Start with SharinPix in 3 Steps

SharinPix is available on the Saleforce [AppExchange](http://bit.ly/SharinPixAppExchange) and can be installed in both **Production** and **Sandbox** environments. This guide walks you through the way to get started in just a few steps, from installing the package to completing the initial configuration needed to connect SharinPix to your Salesforce org.

In this documentation, you will find:

* How to [**install SharinPix from the AppExchange in a Production org**](basic-setup-steps-start-with-sharinpix-in-3-steps.md#install-sharinpix-from-the-app-exchange-in-a-production)
* How to [**install SharinPix from the AppExchange in a Sandbox org**](basic-setup-steps-start-with-sharinpix-in-3-steps.md#install-sharinpix-from-the-app-exchange-in-a-sandbox-environment)
* The [**basic setup steps** ](basic-setup-steps-start-with-sharinpix-in-3-steps.md#basic-setup-steps)to get SharinPix running quickly
* The [**extended setup**](basic-setup-steps-start-with-sharinpix-in-3-steps.md#extended-setup) for additional configuration and advanced options

## Install SharinPix from the App Exchange in Production

Navigate to our AppExchange page by clicking [here.](http://bit.ly/SharinPixAppExchange)

* Log in with your production credentials
* Click the button **Get it Now**

![](<../.gitbook/assets/Screenshot 2024-11-08 at 3.59.05 PM (1) (1).png>)

<figure><img src="../.gitbook/assets/image (2).png" alt=""><figcaption></figcaption></figure>

* Choose which user can access SharinPix
* Click the button **Install**

![](<../.gitbook/assets/ins4 (1) (1).png>)

## Install SharinPix from the App Exchange in a Sandbox

Navigate to our AppExchange page by clicking [here.](http://bit.ly/SharinPixAppExchange)

* Click the button **Try it**

<figure><img src="../.gitbook/assets/1 (2).png" alt=""><figcaption></figcaption></figure>

* For the trial type, select **Try in your Sandbox**

<figure><img src="../.gitbook/assets/2 (2).png" alt=""><figcaption></figcaption></figure>

* Fill in the **Contact Info Section** and click on **Continue to Installation**

<figure><img src="../.gitbook/assets/3 (2).png" alt=""><figcaption></figcaption></figure>

* Click on **Log In & Install**

<figure><img src="../.gitbook/assets/4 (2).png" alt=""><figcaption></figcaption></figure>

* Log in to your Sandbox

<figure><img src="../.gitbook/assets/5 (1).png" alt=""><figcaption></figcaption></figure>

* Choose which user can access SharinPix
* Click the button **Install**

<figure><img src="../.gitbook/assets/6 (1).png" alt=""><figcaption></figcaption></figure>

{% hint style="warning" %}
**Unable to log in to Sandbox**

If you're unable to log in to the Sandbox to install SharinPix, please refer to [this article](https://app.gitbook.com/s/i8tH1o5AHthxksYgF6ij/cannot-log-in-on-sandbox-to-install-sharinpix-what-should-i-do), which explains the steps you should follow.
{% endhint %}
