# What are the uses of Image Sync ?

## Image Sync use

The main use of SharinPix Image Sync is to extract data from  newly-uploaded image and present it in a clear format. The process is automatic and any image that has been uploaded **(1)** is instantly "synchronized"  with its corresponding SharinPix Image recor&#x64;**(2)**.

{% hint style="info" %}
NOTE: In this case, the **Contact** object is used only as an example, however SharinPix Image Sync can be used to display a related list of SharinPix Image records on other types of objects.
{% endhint %}
