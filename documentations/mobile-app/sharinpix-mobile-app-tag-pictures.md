# SharinPix Mobile App: Tag Pictures

This article demonstrates how to define and use the different tag types on the SharinPix mobile app.

## Types of tags

The SharinPix mobile app can be configured with 3 types of tag parameters, namely:

1. [Tags](sharinpix-mobile-app-tag-pictures.md#id-1.-tags) (tags) : The **tags** paremeter takes a label as value(s) which will be then made available for selection in a menu.
2. [Default tags](sharinpix-mobile-app-tag-pictures.md#id-2.-default-tags) (default\_tags): The **default\_tags** parameter takes as value(s) a label that will be selected as the default tag for the captured photos.
3. [Auto tags](sharinpix-mobile-app-tag-pictures.md#id-3.-auto-tags) (auto\_tags): The **auto\_tags** parameter takes as value(s) a label that will be automatically assigned to all photos captured by the app.
