# how can I download images from SharinPix

Once uploaded in SharinPix, images are always available for download.

You can even ask to download the original file, a transformed version (cropped, rotated) with or without annotation.

Here are the different options to download images from SharinPix :

* Right click on image download **is not working**
* Download icon is available by configuration : [Large View toolbar Download](https://app.gitbook.com/s/5EvYRrLbUyvRh8o1jmMG/features/download-images/download-icon-from-the-toolbar)\
  For that you have to set the image\_download ability to true : [SharinPix Abilities](https://app.gitbook.com/s/5EvYRrLbUyvRh8o1jmMG/access-and-security/sharinpix-abilities)\
  This could be done in the VF code page, in the controller code or even globally at the org from the [SharinPix settings](https://app.gitbook.com/s/2putv2B9RAZpym8daOH2/advanced-configuration-customizing-your-sharinpix-components-with-sharinpix-permissions)
* Customizable Download link/button you can add as footer to your VF page : [Image Large View Interaction with Footer](https://app.gitbook.com/s/5EvYRrLbUyvRh8o1jmMG/features/search-images/how-to-personalize-the-image-large-view-and-interaction-footer)
* ZIP download from image selection (require Premium license)
