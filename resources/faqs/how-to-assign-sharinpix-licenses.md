# How to assign SharinPix licenses?

1. From Setup, enter Installed Packages in the Quick Find box, then select Installed Packages.
2. Click Manage Licenses next to the package "ImageManagementBySharinPix"
3. Add or Remove the licenses corresponding to specific users
