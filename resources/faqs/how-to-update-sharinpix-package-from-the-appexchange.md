# How to update the SharinPix package from the AppExchange?

## Why should I update the package?

SharinPix is constantly evolving with provision of new features as well as bug correction at least every month.

Therefore, it is a good practice to update the SharinPix package regularly to be up to date and benefit from these new and exciting features.

## How can I update the SharinPix package?

To update the SharinPix package, follow the steps below:

* Go to setup, search **AppExchange**

![](<.gitbook/assets/Screenshot 2024-11-08 at 3.52.07 PM.png>)

* Search **SharinPix** and select the SharinPix listing installed on your organization. For example, select **IMAGES App by SharinPix - THE Photo / Image Management for Salesforce**

![](<.gitbook/assets/Screenshot 2024-11-08 at 3.49.10 PM.png>)

* Click on the **Get it Now** button.

![](<.gitbook/assets/Screenshot 2024-11-08 at 3.59.05 PM.png>)

**Note:** You may be asked to log in after clicking on the _Get it Now_ button if you have not logged in already. You can log in with your Production credentials if asked.

* Next, click on **Install** **in** **Production** or **Install in Sandbox**. Note: _The AppExchange will detect any existing installation and will update the same without impacting on your current implementation._

![](<.gitbook/assets/image - 2026-01-28T162921.254.png>)

{% hint style="success" %}
**Tip:**

Selecting **Install in Trial** will create a pre-configured **"Learn SharinPix" trial** organization including SharinPix features that you can test.

If requesting a **"Learn SharinPix" trial** , create a username "in email form" (e.g. admin@_mycompany_.trial) and click **Start Free Trial**

Trial users receive an email link to "Verify Account". Click to create a new password for the trial instance and to log into the trial.

_If directed to a login page rather than a prompt to create a password, your company_[ _may be using Office365 with SafeLink_](https://help.salesforce.com/s/articleView?id=000390160\&type=1) \_. Please request assistance acquiring the trial from the AppExchange SharinPix listing's Chat feature.
{% endhint %}

* Click on the button **Confirm and Install**.

![](<.gitbook/assets/image - 2026-01-28T162954.616.png>)

* Choose which user can access SharinPix.
* Click the button **Install**.

![](<.gitbook/assets/image - 2026-01-28T163015.457.png>)

{% hint style="warning" %}
**Note:**

When installing or updating the SharinPix package from the AppExchange, the **Subscription** type always indicates **Free Trial**. Please note that this indication is normal and will in no way impact the installation or update of a paid version of the SharinPix package in your environment.
{% endhint %}
