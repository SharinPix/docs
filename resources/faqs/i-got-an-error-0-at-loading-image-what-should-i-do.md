# I got an error 0 at loading image, what should i do?

If you see the uploader with drag and drop / click to add picture area, you should have done your settings properly.

But if you still can't upload a picture without an error, it may come from a security restriction.

To be sure you are facing a security restriction, you may check this from another connexion (a 3G connexion or a public wifi).

If it works with another connection that means that you may have to white list our API URLs.

The list of those URLs can be find here: [SharinPix Endpoints to Authorize](https://app.gitbook.com/s/5EvYRrLbUyvRh8o1jmMG/access-and-security/sharinpix-endpoint-urls-to-authorize-or-whitelist)
