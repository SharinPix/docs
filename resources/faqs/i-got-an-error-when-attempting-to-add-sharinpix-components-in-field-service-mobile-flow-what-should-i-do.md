# I got an error when attempting to add SharinPix components in Field Service Mobile Flow. What should I do?

When attempting to use the following SharinPix components:

* SharinPix Map
* SharinPix Mobile Launcher
* SharinPix Related Search

in a **Field Service Mobile Flow**, the following error is presented:

![](<.gitbook/assets/image - 2026-01-29T180409.145.png>)

![](<.gitbook/assets/image - 2026-01-29T180543.883.png>)

The above components appear in a Field Service Mobile Flow but, are inoperative in this type of flow.

However, the behaviour of the **SharinPix Mobile Launcher** component can be replicated by making use of a Field Service Mobile Flow that integrates a SharinPix deeplink URL to launch the SharinPix mobile app. For more details on how to make this integration, refer to the following article:

[Integration of SharinPix App with SFS (FSL) App using Flows](https://app.gitbook.com/s/5EvYRrLbUyvRh8o1jmMG/integrations/salesforce-field-service/integration-of-sharinpix-app-with-sfs-fsl-app-using-flows)
