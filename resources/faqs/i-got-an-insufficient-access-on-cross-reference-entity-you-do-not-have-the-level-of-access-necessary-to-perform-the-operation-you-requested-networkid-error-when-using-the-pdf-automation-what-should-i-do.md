# I got an 'INSUFFICIENT\_ACCESS\_ON\_CROSS\_REFERENCE\_ENTITY, You do not have the level of access necessary to perform the operation you requested: \[NetworkId]' error when using the PDF automation. What should I do?

If you got the following error message while configuring the SharinPix to PDF automation:

<mark style="color:$danger;">`INSUFFICIENT_ACCESS_ON_CROSS_REFERENCE_ENTITY, You do not have the level of access necessary to perform the operation you requested. Please contact the owner of the record or your administrator if access is necessary.: [NetworkId]`</mark>

this is most probably because you are using an old version of the SharinPix package.



This issue is a know issue and has already been corrected in recent SharinPix package version.

To resolve this, simply upgrade your SharinPix package. For more information on how to upgrade the package, refer to the following article: [How to update SharinPix package from the AppExchange?](how-to-update-sharinpix-package-from-the-appexchange.md)

{% hint style="warning" %}
**Note:**

If the issue still persists after upgrading the SharinPix package, kindly contact SharinPix support at _sharinpix@support.com_.
{% endhint %}
