# I got an 'invalid page' error message when using a Visualforce page embedding a SharinPix album in Salesforce Community. What should I do?

When adding a Visualforce page embedding a SharinPix album to your Community's page layout, it may happen that the VF page displays the images correctly, but gives the following error message when interacting with the images present on the page:

![](<.gitbook/assets/image - 2026-01-29T180032.797.png>)

This behaviour occurs because by default Visualforce pages do not work on page layouts in Lightning Communities.

For more information about this issue as well as how to resolve the same, kindly refer to the following link:

[Visualforce Page on Page Layout in Lightning Community](https://github.com/edelrabe/Salesforce-Recipes/wiki/Visualforce-Page-on-Page-Layout-in-Lightning-Community)
