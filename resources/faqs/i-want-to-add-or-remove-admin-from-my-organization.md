# I want to add or remove admin from my organization

Login to SharinPix admin dashboard (you need to be an admin first).

Go to: [https://app.sharinpix.com/admin](https://app.sharinpix.com/admin) and Login with Salesforce.

![](<.gitbook/assets/image (4).png>)

Click on the Menu **Users**

![](<.gitbook/assets/image (5).png>)

Edit any user from the list that you want to make an admin or remove as admin.
