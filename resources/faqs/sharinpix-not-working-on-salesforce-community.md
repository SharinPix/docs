# SharinPix not working on Salesforce Community

If you are encountering issues while using SharinPix on a Salesforce Community, here are some configurations that need to be looked into:

* **Check if SharinPix has been properly configured for Salesforce Community**\
  \
  The first thing that needs to be verified is whether SharinPix has been properly configure. Refer to the following article to cross-check the steps required for the configuration:\
  [Enable the usage of SharinPix in Salesforce Community](https://app.gitbook.com/s/5EvYRrLbUyvRh8o1jmMG/features/main-integration/using-sharinpix-in-salesforce-community#enable-the-usage-of-sharinpix-in-salesforce-community)
* **Check if Community users have proper access rights to SharinPix**\
  \
  Some Community users do not have all access rights to SharinPix by default. To provide proper access rights to Community users using the SharinPix components, objects or features, refer to the following article:\
  [SharinPix Community users access rights](https://app.gitbook.com/s/5EvYRrLbUyvRh8o1jmMG/access-and-security/sharinpix-community-users-access-rights)
