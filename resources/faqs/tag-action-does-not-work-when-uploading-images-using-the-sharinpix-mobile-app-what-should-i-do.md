# Tag Action does not work when uploading images using the SharinPix mobile app. What should I do?

By default, the SharinPix Tag Action is not triggered when uploading images using the SharinPix mobile app.

To enable Tag actions for SharinPix mobile app uploads, please refer to section, [Enable Tag actions for SharinPix Mobile App uploads](https://app.gitbook.com/s/5EvYRrLbUyvRh8o1jmMG/features/working-with-tags/tag-action#enable-tag-actions-for-sharinpix-mobile-app-uploads), in the [Tag Action documentation](https://app.gitbook.com/s/5EvYRrLbUyvRh8o1jmMG/features/working-with-tags/tag-action).

## DEPRECATED: Set up workaround for Tag Action when uploading images using the SharinPix mobile app

{% hint style="danger" %}
**Note:**

* This section is deprecated and is only maintained for users who have implemented this feature prior to the Winter '24 Release. It should only be referenced for troubleshooting existing implementations. Support for this deprecated feature will be limited and may be discontinued in future versions.
* For new implementations, please refer to section, [Enable Tag actions for SharinPix Mobile App uploads](https://app.gitbook.com/s/5EvYRrLbUyvRh8o1jmMG/features/working-with-tags/tag-action#enable-tag-actions-for-sharinpix-mobile-app-uploads), in the [Tag Action documentation](https://app.gitbook.com/s/5EvYRrLbUyvRh8o1jmMG/features/working-with-tags/tag-action).
{% endhint %}

The implementation below includes leveraging the **SharinPix Image Sync** and **SharinPix Transformation** features in a Salesforce Flow to update the required field URL when the desired tag is applied, thus mimicking the Tag Action feature.

To set up an action similar to the Tag Action feature, follow the steps below:

* Set up the **Image Sync** feature (if not set up already) for the object you intend to use. For more information on how to set up Image Sync, refer to this article: [Setup SharinPix Image Sync](https://app.gitbook.com/s/5EvYRrLbUyvRh8o1jmMG/image-sync/setup-sharinpix-image-sync)
* Next, set up the **SharinPix Transformation** feature so that it reflects your Tag Action configuration, that is, use the same field name, transformation (i.e., field value such as Fill to size, Pad to size), and value as per your Tag Action configuration.

**Note:** You should use the same _SharinPix Sync Setting_ created in the previous step when configuring the transformation

This transformation will generate an image URL with the configured format. This URL is available on the image's corresponding **SharinPix Image** record.

Save the transformation when done. For more information about SharinPix Transformation and how they are configured, refer to the following article: [SharinPix Transformation - get your images automatically resized!](https://app.gitbook.com/s/5EvYRrLbUyvRh8o1jmMG/image-sync/sharinpix-transformation-get-your-images-automatically-resized)

* Once you configured the Image Sync and Transformation, create a Flow on the **SharinPix Image** object that will copy the URL generated from the SharinPix Image field to the desired object field as explained below:
  * Create a record-triggered Flow.

![](<.gitbook/assets/image (6).png>)

Fill in the _Configure Start_ modal as follows:

* **Object:** SharinPix Image
* **Trigger the Flow When:** A record is created or updated
* **Condition Requirements:** All Conditions Are Met (AND)
* **Field:** sharinpix\_\_Tags\_\_c
* **Operator:** Contains
* **Value:** main _(or the technical name of the tag of your choice)_

![](<.gitbook/assets/image (7).png>)

{% hint style="warning" %}
**Note:**

The previous step is where you specify the desired tag. In this scenario, we are using the **main** tag.
{% endhint %}

* Add an **Update Triggering Records** element.

![](<.gitbook/assets/image (8).png>)

![](<.gitbook/assets/image (9).png>)

* On the _Update Triggering Record_ modal, enter the following information:
  * **Label:** Update Account Record
  * **How to Find Records to Update and Set Their Values:** Specify conditions to identify records, and set fields individually
  * **Object:** Account
  * In the **Field Account Records** section:
    * **Condition Requirements to Update Record:** All Conditions Are Met (AND)
    * **Field:** Id
    * **Operator:** Equals
    * **Value:** {!$Record.sharinpix\_\_Account\_\_c}
  * In the **Set Field Values for the Account Records** section:
    * For the **Field**, select the Account field in which you want to store the image URL generated by the tag action.
    * For the **Value**, choose the field used in the SharinPix Transformation configuration.
    * Click **Done** to save and activate the Flow.
