# What is the difference between the LITE Plan, PRO Plan, ENTERPRISE Plan and FORM Plan?

SharinPix pricing is coming with 3 different Plans for Salesforce User.

* LITE Plan dedicated to Lite Photo Usage: Upload, View (limited)
* PRO Plan dedicated to Professional Image Usage including Salesforce Interaction and Automation
* ENTERPRISE Plan with Full Field Service support and Advanced capabilities including Video, Gen AI, Floor Plan, Aerail View and more
* FORM Plan with Offline mobile form capabilities, includes all the ENTERPRISE features and more

**You can't have licenses on both plan on the same Salesforce organisation.**

![](<.gitbook/assets/image (25).png>)

## LITE Plan

LITE plan includes features which permits the very basic of Uploading images, viewing basic image format and limited edition tool.

It includes :&#x20;

* Unlimited Storage (for images upload by a user with a SharinPix licenses)
* Album Component (Gallery with upload / thumbnail view / large view)
* Single Image Component (upload and view single image)
* Basic Image format  ( JPG PNG GIF BMP  )

Components are only available for Record Page Builder.\
This plan can't be used on mobile and is only for desktop usage, not supported for Experience Cloud

_**For integration in Flow screen, Mobile Flow screen, your own personalised Components and invocable methods from Flows and Development, check the PRO Plan.**_

_**For integration with Field Service mobile app and Field Service mobile Flow screen, check the ENTERPRISE Plan.**_

## PRO Plan

PRO plan includes all options and features coming with the LITE Plan.

It includes  the SharinPix mobile App with online Components.



The features available only for PRO Plan are:

* Interaction Components including
  * [Copy to Rich Text](https://app.gitbook.com/s/5EvYRrLbUyvRh8o1jmMG/lightning-web-component/sharinpix-to-rich-text-area)
  * [Copy to Clipboard](https://app.gitbook.com/s/5EvYRrLbUyvRh8o1jmMG/lightning-web-component/sharinpix-copy-to-clipboard)
  * [Copy to PDF](https://app.gitbook.com/s/5EvYRrLbUyvRh8o1jmMG/lightning-web-component/sharinpix-to-pdf)
  * [Image Collage](https://app.gitbook.com/s/5EvYRrLbUyvRh8o1jmMG/lightning-web-component/sharinpix-collage) (Before/After)
  * Webform integration
  * [Import Files](https://app.gitbook.com/s/5EvYRrLbUyvRh8o1jmMG/lightning-web-component/sharinpix-import-files)
  * Checklist
  * and more...
* Extended Image Format : CR2 PDF EPS PSD AI TIFF
* Other format storage : store none image format (without rendering by SharinPix)
* Annotation : vectorial tools avaialble to draw annotation on top of any pictures
* Download as Zip : extract from Album or Search Result  a zip file containing the selected images (zip file name and image file name could be personalized).
* Tag and Search: Apply Personalized Tag on Pictures and Search for Pictures across records.
* External Share ( Share Link, Smart Share, Public Images - requires extra cost based on volume )
* Image as Salesforce Fields : Sync tagged image resized version as URL in Salesforce field
* Image as Salesforce Record : extend your Salesforce with Image metadata and image contents available for your Salesforce process (document generation, views, reports, counting images, geolocation integrate with external system, external website )
* Watermark : automate watermark on images at upload to time stamp or to relocate your photos  - automate watermark to protect images with your logo or information on it
* Advanced Uploader : Upload Images directly from your webcam, from Image web search, from Social Media Search.
* Generate PDF (Quick configurable Visit report including some fields from Saleforce and optimised image tables)

_**For integration with Field Service mobile app and Field Service mobile Flow screen, check the ENTERPRISE Plan.**_

## ENTERPRISE Plan

ENTERPRISE  plan includes all options and features coming with the PRO and LITE Plan.

ENTERPRISE plan is mandatory for any usage with Field Service integration.

For Field Service it includes integration of SharinPix offline mobile app, of the Offline experience with LWC and the integration with Document builder including several different components for a better photo integration in PDFs.

Offline support is also included for any Saleforce offline mobile offer (Salesforce mobile app+, Salesforce CG CLoud offline mobile app and any 3rd party app connected to Salesforce).



The SharinPix offline mobile app allows access to the following :&#x20;

* Scan Documents : snap to PDF with automatic edge detection and OCR
* Snap and Say : to dictate your comment to be added on pictures while taking them
* Room scan : to capture a 3D Twin of rooms that will be available on desktop with 3D rendering and measurement and will allow as well 2D floor plan generation
* Video capture : which can be then rendered on the desktop (requires the usage of your own storage)
* PDF form capabilities : Sign, Fill and takes pictures from PDF form
* Dynamic form access (require the SharinPix form app license)



ENTERPRISE plan also includes various experience on desktop and mobile with :&#x20;

* Areal view with screen shot, annotations and area calculation (from integrated Google Map)
* Interactive Floor Plan with checkpoints and Annotations (from PDF plan- upload your PDF and start working on it to place remarks - designed to work on tablets and phones)
* Gen Ai automation to extract information from provided documents and photos
* Spilt, Merge and edit PDF files
* Office Document viewer (view and search keyword in Word, Powerpoint and Excel documents)

## FORM Plan

FORM plan includes all options and features coming with the ENTERPRISE, the PRO and LITE Plan.

With a FORM Plan license a user can create, edit and manage SharinPix Form templates.

Those forms can be then available to any FORM Plan user to be open either :&#x20;

* from Salesforce mobile app using the Mobile Form Launcher component
* from Salesforce field service mobile app using the AppExtension or Field Service mobile flow integration
* from text, whatsapp, emails, agenda, documents by clicking on a provide link

Once submitted a form is available as a Form Response in Salesforce, which could be accessed by FORM Plan users in Salesforce.

This will present a quick overview of the form, will present Answers as record in Salesforce and is coming with a Generated PDF.
