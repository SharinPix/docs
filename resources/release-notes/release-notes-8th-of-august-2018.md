# Release Notes - 8th of August 2018

**New Features**

* Uploader display don't show up Drag and Drop anymore when used on mobile
* Increased Max file size to 100Mb
* Tag Display on SharinPix Search result
* Display object metadata on SharinPix Search result
* Upload Picture button as Lightning Component (Album like Add button without image display)
* Higher Resolution display as option form Large View

**Bugs Corrected**

* Null date taken when using SharinPix mobile App
* Various UI and sync image bug from SharinPix mobile App
* Improved SharinPix mobile App feedback
