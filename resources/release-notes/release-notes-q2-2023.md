# Release Notes - Q2 2023

## Known Bug with correction

* SharinPix Mobile App: Torch (flashlight) is on even if not opening the capture page
* SharinPix Mobile App: Unable to exit the App when using deeplink twice
* SharinPix Mobile App: Redirect to Checklist for Await\_Upload
* SharinPix Mobile App: Torch (flashlight) icon not showing when opening multiple deeplinks
* SharinPix Mobile App: Batch page image preview is not visible when the page is scrolled
* SharinPix Mobile App: Annotation not working on image rotation
* SharinPix Mobile App: Unable to use the SharinPix App while using another application
* SharinPix Mobile App: Annotation on the image moves when the keyboard is used
* SharinPix Image: Viewer info overlaps the image toolbar
* SharinPix Single Image: Caption overlay on new image

## Features

* SharinPix Mobile App: Green Icon to indicate image uploaded successfully
* SharinPix Mobile App: Modify the limit for uploading images in bulk
* SharinPix Mobile App: New UI
* SharinPix Image: Render files in .glb format
* SharinPix Image: Add a parameter to display the image instead of downloading
* [SharinPix Image: Disable information "i" icon](https://app.gitbook.com/s/5EvYRrLbUyvRh8o1jmMG/features/user-interface/large-view-toolbar-information)
* SharinPix Document Viewer: Optimised Viewer for Documents(docx, pptx, xlsx, pdf)
* SharinPix Single Image: Image Caption/Annotation/Annotation visibility
* SharinPix Image: Sort Enhancement
