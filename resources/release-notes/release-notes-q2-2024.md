# Release Notes - Q2 2024

Known Bug with correction

* SharinPix Mobile App: Team checklist - Landscape image not displaying correctly on checklist
* SharinPix Mobile App: Android (< v11) – Excessive compression created low-quality photos
* SharinPix Copy to Clipboard Component: Images got smaller when copied
* SharinPix Album within Community: Page refresh cancelled remaining uploads during multi-image upload

New Features

* SharinPix Mobile App: [Form Checklist](https://app.gitbook.com/s/5EvYRrLbUyvRh8o1jmMG/mobile-app/sharinpix-mobile-app-checklist-with-form-features)
* SharinPix Mobile App: PDF Form - [Photo Field Enhancement with template image](https://app.gitbook.com/s/5EvYRrLbUyvRh8o1jmMG/mobile-app/sharinpix-pdf-photo-field#template_image)
* SharinPix Mobile App: [Wide-angle camera option](https://app.gitbook.com/s/5EvYRrLbUyvRh8o1jmMG/mobile-app/sharinpix-mobile-app-deeplink-syntax#lens) on supported devices
* SharinPix Mobile App: [Export Feature](https://app.gitbook.com/s/5EvYRrLbUyvRh8o1jmMG/mobile-app/export-media-to-internal-storage) to save media from SharinPix Mobile App to the current device
* SharinPix Mobile App: Team Checklist Enhancement - New ordering of images by date taken
* SharinPix Mobile App: Form Checklist + Team Checklist Enhancement - [Alert Text configurable](https://app.gitbook.com/s/5EvYRrLbUyvRh8o1jmMG/mobile-app/sharinpix-mobile-app-checklist-with-form-features#additional-configurations)
* SharinPix Mobile App and Album: [Annotation Configurator](https://app.gitbook.com/s/5EvYRrLbUyvRh8o1jmMG/features/user-interface/annotations-configurator) Enhancements
* SharinPix Album: Merge Annotations (Overlay multiple Image annotations on a given image)
* SharinPix Album: [Infinite Scroll View](https://app.gitbook.com/s/5EvYRrLbUyvRh8o1jmMG/features/user-interface/thumbnail-view-album-gallery-navigation#gallery-navigation-scroll)
* SharinPix Single-Image Component: Tags can now be displayed through [SharinPix permission](https://app.gitbook.com/s/5EvYRrLbUyvRh8o1jmMG/access-and-security/sharinpix-permission-object-how-to-create-and-assign-custom-permission)
* SharinPix App: [Request SharinPix License from Production](https://app.gitbook.com/s/5EvYRrLbUyvRh8o1jmMG/features/user-interface/sharinpix-add-licenses)
* SharinPix Transformation: [Reformat image as JPG](https://app.gitbook.com/s/5EvYRrLbUyvRh8o1jmMG/image-sync/sharinpix-transformation-flow)
* SharinPix Playground – [SharinPix AI capabilities demo](https://app.gitbook.com/s/5EvYRrLbUyvRh8o1jmMG/cookbook/sharinpix-generative-ai-analysis-extract-image-capabilities)
* [SharinPix Upload button (LWC)](https://app.gitbook.com/s/5EvYRrLbUyvRh8o1jmMG/cookbook/display-an-upload-button-in-a-lightning-web-component)

* [SharinPix Plan Items Related List](https://app.gitbook.com/s/5EvYRrLbUyvRh8o1jmMG/lightning-web-component/sharinpix-plan-items-related-list): Available in Community
