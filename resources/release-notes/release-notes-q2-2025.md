# Release Notes - Q2 2025

Known Bug with correction

* SharinPix Mobile App: Alert Box remaining on page when opening another mode on the SharinPix Mobile App
* SharinPix Album: Improved screen reader support by adding accessible label to delete button
* SharinPix Album: Fixed bug where pressing "Delete" triggered multiple image dialogs and bulk deletion
* SharinPix Form: Form Response not created due to batch not related to form
* SharinPix Form: Rich Text fields did not take the full width of the form
* SharinPix Form: Can view filled form on SharinPix Mobile App from Job page

New Features

* SharinPix Mobile App: Hide all Annotations after selecting to provide a more user-friendly interface to annotate on the image
* SharinPix Form: Prefilled Value for Question Elements
* SharinPix Form: Conditional Visibility on Form Element
* SharinPix Form: Comparative Functionality
* SharinPix PDF Form Builder: Prefilled Value for template-image for Photo Fields
