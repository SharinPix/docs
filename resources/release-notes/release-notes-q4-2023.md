# Release Notes - Q4 2023

## Known Bug with correction

* SharinPix Mobile App: Unsubmitted batch Image redirecting to the camera
* SharinPix Mobile App: Team checklist is not updated while using two different devices
* SharinPix Mobile App: Unable to save images with HEIC formats
* Sharinpix Album: LWC Album not displaying Custom label
* SharinPix Album: Image info overlaps on Album viewer
* SharinPix Album: Screen freezes upon drag and drop of an image on album

## Features

* SharinPix Mobile App: Exif with images selected from roll (Available only for images with JPEG format)
* SharinPix: New Component [SharinPix Share](https://app.gitbook.com/s/5EvYRrLbUyvRh8o1jmMG/lightning-web-component/sharinpix-share) (_allows to generate and share URL select images or album. This is available across any platform/device_).
* SharinPix Album: Share selected images with custom positioning
* SharinPix Album: Zip file name enhancement
* SharinPix Album: Sort Dropdown visibility
